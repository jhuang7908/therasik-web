贷款助理上岗实务班

Loan Assistant Onboarding Program

本课程为岗位技能培训，帮助您在贷款团队担任助理角色。不含贷款经纪人（MLO）执照考试辅导，也不含房地产经纪课程。
This is a job-skills program for assistant roles in mortgage teams. It does not include MLO license exam prep or real estate licensing.
  • 模块 1 — 房贷全流程：从客户咨询到结案过户
  • Module 1 — End-to-end mortgage workflow
  • 模块 2 — 资料收档清单：申请表、收入、资产与信用文件
  • Module 2 — Document intake & file checklists
  • 模块 3 — 客户沟通：电话、邮件与微信跟进话术（中英）
  • Module 3 — Client communication best practices (EN/ZH)
  • 模块 4 — 合规要点：客户隐私、宣传用语与审批承诺边界
  • Module 4 — Compliance essentials for assistants
  • 模块 5 — 业务系统入门：任务跟进、截止日期与文件状态
  • Module 5 — Pipeline tracking & deadline management
  • 模块 6 — 综合案例演练 + 讲师 Zoom 答疑
  • Module 6 — Capstone case study + instructor review
